# BLUER — Order Confirmation Email Template

A responsive HTML email template developed as a frontend assignment for **BLUER**, based on a provided Figma design.

The project recreates a premium, minimalistic order confirmation email with a dark-themed interface, fashion product imagery, order information, and customer support details.

## Project Overview

The objective was to translate the provided Figma design into a functional HTML email while maintaining visual consistency, clean code, and compatibility with email clients.

The implementation focuses on reproducing the original design's typography, spacing, alignment, imagery, and overall visual hierarchy.

## Features

- **Order Confirmation:** Displays the order confirmation message, order number, and purchase date.
- **Product Summary:** Showcases purchased products with images, names, sizes, and prices.
- **Pricing Breakdown:** Includes subtotal, discount, shipping charges, taxes, and total amount.
- **Customer Information:** Displays payment method and shipping details.
- **Discover Section:** Features additional fashion collections with promotional imagery.
- **Branded Footer:** Includes customer support information, useful links, and BLUER branding.
- **Email-Friendly Layout:** Uses HTML and inline CSS to support rendering across email clients.

## Design Reference

The original design follows a monochromatic aesthetic with product-focused visuals, uppercase headings, and carefully structured spacing.

## Implementation Approach

1. Analyzed the Figma reference to identify the email's layout, sections, and styling.
2. Developed the email structure using semantic HTML and email-compatible layout techniques.
3. Applied inline CSS for consistent visual presentation.
4. Incorporated the provided fashion product images.
5. Recreated the order details, pricing breakdown, promotional section, and footer.
6. Uploaded the project assets to GitHub and configured public image paths.
7. Previewed the HTML locally in a web browser.

## Running Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Dimple2706/bluer-email-template.git
   ```

2. Navigate to the project folder:

   ```bash
   cd bluer-email-template
   ```

3. Open `index.html` in any modern web browser.

No package installation or build process is required.

## Email Compatibility

The template is designed with email-specific development practices, including inline styling, table-based layouts, and publicly accessible image URLs.

**Note:** Final compatibility and rendering should be verified in Gmail, Outlook, and mobile email clients before production use.
